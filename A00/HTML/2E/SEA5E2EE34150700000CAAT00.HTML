M/T System Description - Differential

Four Pinion Type Differential


Function

Four pinion type differential to downsize the differential body. Also, using the four pinion lower the initial backlash and reduces the noise from driveline.

Construction

Four pinion type differential consists of two side gears, four pinion gears and two pinion shafts.
The differential assembly cannot be disassembled. If there is a problem with the differential, replace it as an assembly.
