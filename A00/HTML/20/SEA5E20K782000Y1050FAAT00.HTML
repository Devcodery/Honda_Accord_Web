DTC Troubleshooting: B1050, B1100, B1150, B1200, B1250, B1300

DTC B1050, B1100, B1150, B1200, B1250, B1300:  Communication Bus Line Error


1.Clear the DTCs using the HDS.

2.Cycle the ignition switch to OFF, and then back ON.

3.Check the DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Are DTC(s) B1050, B1100, B1150, B1200, B1250, or B1300 indicated?


YES - Go to 4.


NO - Intermittent failure, the system is OK at this time.n


4.Check the DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Is DTC(s) B1000 indicated?


YES - Troubleshoot DTC B1000.n


NO - If DTC B1050 is indicated, replace the relay module. If DTC B1100 is indicated, replace the door multiplex control unit. If DTC B1150 is indicated, troubleshoot DTC B1150. If DTC B1200 is indicated, replace the  combination switch control unit.n
