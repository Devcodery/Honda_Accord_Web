Power Tailgate Control Unit Input Test

1.Remove these items:

  • Center pillar upper trim
  • Quarter pillar trim
  • Roof end trim
  • Grab handle

2.Headliner is lowered.

3.Disconnect connector A (26P) and connector B (5P) (A) from the power tailgate control unit (B).

 

4.Inspect the connectors and socket terminals to be sure they are all making good contact.

  • If the terminals are bent, loose or corroded, repair them as necessary, and recheck the system.
  • If the terminals look OK, go to 4.

5.With the connector still disconnected, make these input tests at the connectors.
  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If all the input tests prove OK, go to 5.

Cavity Wire Test condition Test: desired result Possible cause if result is not obtained 
A1 WHT/RED Under all conditions Check for voltage to ground: There should be battery voltage. 
  • Blown No. 7 (10 A) fuse in the under-dash fuse/relay box
  • An open in the wire
 
A2 YEL Ignition switch ON (II) Check for voltage to ground: There should be battery voltage. 
  • Blown No. 21 (7.5 A) fuse in the under-dash fuse/relay box
  • An open in the wire
 
B2 WHT/GRN Under all conditions Check for voltage to ground: There should be battery voltage. 
  • Blown No. 42 (40 A) fuse in the under-hood subfuse box
  • An open in the wire
 
B1 WHT/YEL Under all conditions Check for voltage to ground: There should be battery voltage. 
  • Blown No. 41 (20 A) fuse in the under-hood subfuse box
  • An open in the wire
 
A24 YEL/BLK Under all conditions Attach to ground: Power tailgate indicator light should come on. 
  • Blown No. 7 (10 A) fuse in the under-dash fuse/relay box
  • Faulty gauge control module
  • An open in the wire
 
A15 BLK Under all conditions Check for continuity to ground: There should be continuity. 
  • Poor ground (G705)
  • An open in the wire
 
B3 BLK Under all conditions Check for continuity to ground: There should be continuity. 
  • Poor ground (G705)
  • An open in the wire
 
B5 BLK Under all conditions Check for continuity to ground: There should be continuity. 
  • Poor ground (G705)
  • An open in the wire
 


6.Reconnect connectors A (26P) and B (5P) to the power tailgate control unit, and perform the following input taste.
  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If all input tests prove OK, the control unit must be faulty, replace the power tailgate control unit.
