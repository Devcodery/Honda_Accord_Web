MICS Troubleshooting - Test Mode B

B-CAN System Diagnosis Test Mode B


NOTE:
  • Because several different tester's can be used to troubleshoot, there might be differences in what is shown on the screen and what is shown in the DTC troubleshooting flow charts in the Shop Manual.
  • Perform this diagnosis if any of the control units are not communicating (N/A displayed in the HDS) as found by the B-CAN System Diagnosis Mode A.
  • Always cycle the ignition switch within 3 seconds when prompted in the DTC troubleshooting procedures.

1.Using the HDS, select the system that has the symptom from the BODY ELECTRICAL MENU.

Are the loss of communication DTCs indicated?


YES - Go to 2.


NO - Replace the  MICU.n


2.Select DTCs, and then check for loss of communication DTCs (use the DTC troubleshooting to find the DTC type).

3.Perform the input test for the unit not communicating with the HDS.

Unit not communicating 
MICU 
Door multiplex control unit 
Gauge control Module 
Relay control Module
