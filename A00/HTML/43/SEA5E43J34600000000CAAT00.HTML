Troubleshooting the CAN circuit related problems


Using the HDS (Preferred method)


1.Go to B-CAN system diagnosis test mode A.

2.If no DTCs are retrieved, go to Test Mode C or D.

Without the HDS
(Should be used if the HDS is unavailable)


3.Check for communication circuit problems using Mode 1.

4.Check for DTCs while in Mode A.

5.Sort, and then troubleshoot the DTCs in the order below. Refer to the DTC troubleshooting for DTC descriptions.

1st. Internal Error DTCs 
2nd. Loss of communication DTCs 
3rd. Signal Error DTCs 


6.If no DTCs are retrieved, use mode 2 to check all inputs related to failure.
