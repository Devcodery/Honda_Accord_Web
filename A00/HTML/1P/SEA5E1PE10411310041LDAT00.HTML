A/T Clutch Reassembly

Special Tools Required
Clutch spring compressor set (  07LAE-PX40000)
 

Clutch spring compressor attachment (   07LAE-PX40100)
 
Clutch spring compressor attachment (   07HAE-PL50101)
 
Clutch spring compressor bolt assembly (   07GAE-PG40200)
 
Snap ring pliers (  07LGC-0010100)
 



1.Soak the clutch discs thoroughly in ATF for a minimum of 30 minutes.

2.Install the new O-rings (A) on the 4th and 5th clutch piston (B).

 

3.Install the new O-ring (A) in the 1st, 2nd, and 3rd clutch pistons (B), and install the new O-ring (C) on the clutch drums (D).

 

4.Install the clutch piston (A) in the clutch drum (B). Apply pressure and rotate to ensure proper seating. Lubricate the piston O-ring with ATF before installing. Do not pinch the O-ring by installing the piston with to much force.

 

5.Install the return spring (A) and spring retainer (B), and position the snap ring (C) on the retainer.

 

6.Install the special tools.

 

7.Be sure the special tool (A) is adjusted to have full contact with the spring retainer (B) on the 4th and 5th clutches.

 

8.Set the special tool (A) on the spring retainer (B) of the 1st, 2nd, and 3rd clutches in such a way that the special tool compresses the clutch return spring (C).

 

9.If either end of the special tool is set over an area of the spring retainer which is unsupported by the return spring, the retainer may be damaged.

 

10.Compress the return spring.

 

11.Install the snap ring with snap ring pliers.

 

12.Remove the special tools.

13.For K20A6 Engine model 1st Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch waved-plates (C) (4), and discs (D) (4), and install the clutch-end-plate (E) with the flat side toward the disc.

 

14.For K20A6 Engine model 2nd Clutch:
Install the waved spring (A) in the clutch drum (B). Install the clutch flat-plate (C), and clutch disc (D). Starting with the clutch waved-plate, alternately install the clutch waved-plates (E) (3), and discs (F) (3), and install the clutch-end-plate (G) with the flat side toward the disc.

 

15.For K20A6 Engine model 3rd Clutch:
Install the waved spring (A) in the clutch drum (B). Install the clutch flat-plate (C), and clutch disc (D). Starting with the clutch waved-plate, alternately install the clutch waved-plates (E) (3), and discs (F) (3), and install the clutch-end-plate (G) with the flat side toward the disc.

 

16.For K20A6 Engine model 4th Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch waved-plates (C) (3), and discs (D) (3), and install the clutch-end-plate (E) with the flat side toward the disc.

 

17.For K20A6 Engine model 5th Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch waved-plates (C) (3), and discs (D) (3), and install the clutch-end-plate (E) with the flat side toward the disc.

 

18.For K24A3 Engine model 1st Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch plate, alternately install the clutch plate (C) (5) and discs (D) (5), then install the clutch-end-plate (E) with the flat side toward the disc.

 

19.For K24A3 Engine model 2nd Clutch:
Install the waved spring (A) in the clutch drum (B). Install the 4.0 mm-thick plate (C) with the sheer droop side (D) toward the inside of the drum, clutch disc (E), and 2.0 mm-thick flat-plate (F), then starting with the disc, alternately install the discs (G) (4) and waved-plates (H) (3), then install the clutch-end-plate (I) with the flat side toward the disc.

 

20.For K24A3 Engine model 3rd Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch plate, alternately install the clutch plate (C) (5) and discs (D) (5), then install the clutch-end-plate (E) with the flat side toward the disc.

 

21.For K24A3 Engine model 4th Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch plates (C) (4) and discs (D) (4), then install the clutch-end-plate (E) with the flat side toward the disc.

 

22.For K24A3 Engine model 5th Clutch:
Install the waved spring (A) in the clutch drum (B). Starting with the clutch waved-plate, alternately install the clutch plates (C) (4) and discs (D) (4), then install the clutch-end-plate (E) with the flat side toward the disc.

 

23.Install the snap ring with a screwdriver.

 

24.Check that the clutch piston moves by applying air pressure into fluid passage.
