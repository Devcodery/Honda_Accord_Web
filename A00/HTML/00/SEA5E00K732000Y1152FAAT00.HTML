DTC Troubleshooting: B1152

DTC B1152:  Gauge Control Module EEPROM Error


1.Clear the DTCs using the HDS.

2.Start the engine.

3.Check for DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Is DTC B1152 indicated?


YES - Faulty gauge control module; replace the gauge control module.n


NO - Intermittent failure, the gauge control module is OK at this time.n
