DTC Troubleshooting: B1150

DTC B1150:  Communication Bus Line Error


1.Check the DTCs by selecting the DTCs MENU (DTCs) with the HDS.

In addition to DTC B1150, are any of these DTCs indicated: B1155, B1156, B1157, B1159, and/or B1160?

YES - Go to 2.

NO - Go to 3.


2.Check the DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Are there any DTCs not listed in step 1?

YES - Troubleshoot the DTC(s) related to the functional problem.n

NO - Go to 3.


3.Clear the DTCs by selecting the CLEAR MENU (DTC CLEAR) with the HDS.

4.Cycle the ignition switch OFF, and then back to ON within 3 seconds.

5.Check the DTCs by selecting the DTCs MENU (DTCs) with the HDS.

Is DTC B1000 indicated?

YES - Troubleshoot DTC B1000.n

NO - If no DTC(s) are indicated and no problems exist, it is an intermittent failure, the system is OK at this time. If no DTC(s) are indicated and there is still a problem, go to system diagnosis test mode C or D. If a DTC(s) other than DTC B1000 is indicated, go to 6.


6.Check the DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Is DTC B1008 indicated?

YES - Troubleshoot DTC B1008.n

NO - Go to 7.


7.Check the DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Is only DTC B1150 indicated?

YES - Faulty gauge control module: replace the  gauge control module.n

NO - Go to the DTC troubleshooting index and start troubleshooting with the lowest numerical DTC.n
