DTC Troubleshooting: B1055, B1056, B1057, B1058, B1059, B1060, B1061, B1062, B1063

B1055:  Relay Control Module lost communication with MICU
  
  
B1057:  Relay Control Module lost communication with MICU (door switch message)
  
  
B1059:  Relay Control Module lost communication with Door Multiplex Control Unit (panic message)
  
  
B1061:  Relay Control Module lost communication with Gauge Control Module (A/T message)
  
  
B1063:  Relay Control Module lost communication with Combination Switch Control Unit (wiper switch message)


1.Clear the DTCs using the HDS.

2.Cycle the ignition switch OFF then ON.

3.Check for DTCs by selecting the DTCs MENU (DTCs) from the HDS.

Is DTC B1055, B1056, B1057, B1058, B1059, B1060, B1061, B1062 and/or B1063 indicated?


YES - Go to 4.


NO - Intermittent failure, the F-CAN communication line is OK at this time.n

4.Check for DTCs other than those listed above.

Are any other DTCs present?


YES - Go to 5.


NO - Perform Relay Control Module Input Test.n


5.Find the chart that contains at least one retrieved DTC in column A and one retrieved DTC in column B. Perform the input test for the ECU listed in that chart.
If no DTC from column B is found then continue to Relay Control Module input test.n
