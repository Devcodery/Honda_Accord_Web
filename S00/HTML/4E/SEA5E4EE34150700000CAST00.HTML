Descripción del sistema de la M/T - Diferencial

Diferencial del tipo cuatro piñones


Función

Diferencial del tipo cuatro piñones para reducir el tamaño del cuerpo del diferencial. También, se utiliza el cuatro piñones para disminuir el juego y reducir el ruido procedente de la cadena cinemática.

Construcción

El diferencial del tipo cuatro piñones consta de dos planetarios, cuatro piñones satélite y dos ejes de piñón.
EL conjunto del diferencial no se puede desmontar. Si apareciera algún problema con el diferencial, sustitúyalo como un conjunto.
