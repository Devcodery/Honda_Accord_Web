Sistema de entrada sin llaves/alarma de seguridad - Sensor recordatorio activado

El sistema de seguridad guarda la información del último sensor disparado si se ha violado este sistema. La información puede recuperarse utilizando el HDS.

Para recuperar los datos del último sensor disparado:

1.Seleccione HISTORIAL DE DATOS en el menú del modo de comprobación del sistema de seguridad.

2.Seleccione DATOS ACTUALES.

3.Confirme que el VIN concuerda con el del vehículo y a continuación pulse el botón Enter.

4.Efectúe un recorrido por la lista de datos.

  • Los sensores que hayan sufrido una violación estarán indicados con la palabra DETECCIÓN (DETECT).
  • Los sensores que no hayan sufrido una violación estarán indicados con la palabra NINGUNA (NONE).

5.Inspeccione el circuito de DETECCIÓN (DETECT) en busca de:

  • Un interruptor desajustado o dañado.
  • Unas conexiones sueltas u oxidadas.
  • Una derivación a masa intermitente.
