Fluidos y lubricantes



El aceite del motor usado puede provocar cáncer de piel si se mantiene un contacto prolongado con el mismo durante largos períodos de tiempo.
Aunque esto resulte improbable, a menos que el manejo de este aceite se efectúe diariamente, es aconsejable lavarse las manos con agua y jabón, a la mayor brevedad posible, después de su manipulación.


Para más información sobre los puntos de lubricación y el tipo de lubricantes que hay que utilizar, consulte el índice ilustrado y distintos procedimientos de trabajo (como montaje/remontaje, sustitución, revisión, instalación, etc.) en cada sección.

B Caja de cambios manual Cambio del aceite para cajas de cambio manuales (MTF)
Utilice siempre MTF-II original de Honda. El uso de aceite para motor puede endurecer el cambio de marcha, ya que no contiene los aditivos apropiados. 
Caja de cambios automática ATF-Z1 original de Honda
Utilice siempre ATF-Z1 original de Honda. La calidad del cambio de las velocidades puede verse afectada si se utiliza un ATF que no sea original de Honda. 
C Sistema de frenos (incluyendo la tubería ABS) Líquido de frenos DOT 3 ó DOT 4
Recomendamos el líquido de frenos original de Honda. El uso de un líquido de frenos que no sea original de Honda puede causar corrosión y reducir el tiempo de vida del sistema.
